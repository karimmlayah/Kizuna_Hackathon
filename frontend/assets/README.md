# Ressources locales

`logo.svg` et `icon.png` : identité originale Smart Solar, générée par `scripts/create-assets.cjs`. Pas de contenu tiers incorporé dans ces fichiers.

La maison, les panneaux, la batterie, l’onduleur, les arbres et le toit de démonstration sont dessinés par les sources de `scenes/` et `components/RoofCanvas.tsx`. Aucun téléchargement de modèle ou texture n’est nécessaire. La scène native réemploie les mêmes codes visuels avec une géométrie SVG distincte.
